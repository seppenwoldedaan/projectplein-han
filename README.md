# Projectplein

Een volledig klikbaar prototype voor een projectplatform van een onderwijsinstelling. Opleidingen plaatsen projecten en studenten zoeken, filteren en schrijven zich in.

## Prototype bekijken

Open `index.html` in een browser. Alle voorbeeldgegevens en interacties werken lokaal. Inloggen, projecten plaatsen en inschrijvingen worden alleen in de lokale browser opgeslagen.

## Belangrijk

De OSIRIS-login is een demonstratie. Er is geen koppeling met HAN, OSIRIS of een externe database. Het ontwerp gebruikt geen HAN-logo en presenteert zich niet als officiële HAN-dienst.

## Publiceren via GitHub Pages

1. Maak een nieuwe repository op GitHub.
2. Voeg `index.html`, `styles.css` en `app.js` toe aan de hoofdmap van de repository.
3. Open in GitHub de instellingen van de repository.
4. Kies bij Pages voor publicatie vanaf de hoofdbranch en de hoofdmap.
5. GitHub toont daarna de openbare URL.
